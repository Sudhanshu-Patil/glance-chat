A robot that answers for you.

Glance is a floating assistant for your portfolio. It follows the cursor, blinks, gets happy, thinks, and answers visitors' questions about you. It reads your portfolio by itself, so there's nothing to write or paste. Free to run on Vercel and Groq. Try it in the corner.

Deploy your own on Vercel Setup guide on GitHub
All you need before you deploy
  1. A free Groq API key. Create one here, it takes a minute and needs no card. Vercel asks for it as GROQ_API_KEY.
  2. Your portfolio's address, like https://yourname.dev. Vercel asks for it as ALLOWED_ORIGINS, so only your site can use your robot. Add http://localhost:5173 after a comma if you test locally.
  3. Access to your portfolio's HTML, to paste one script tag. Glance reads your site's content by itself.

Your Glance is live. Next steps

  1. Style it. Pick colours, shape and theme below. The robot in the corner updates live.
  2. Put it on your portfolio. Copy the snippet at the bottom of this page and paste it just before </body> in your site's HTML (in React or Vite apps that's index.html). Your portfolio stays where it is; the robot loads from this deployment and learns from your site's pages. Ask it something there to try it. The robot on this page won't know you yet, because it doesn't read this setup page.
  3. Allowed sites. Only the sites in ALLOWED_ORIGINS can use this robot. To change them, edit ALLOWED_ORIGINS in this project's Vercel Settings, then Environment Variables, and redeploy. If the robot on your portfolio says it isn't set up for the site, its address is missing from this list.
  4. Optional: add detail that isn't on your site. Add a RESUME_TEXT environment variable in Vercel with your resume text (open it, Ctrl+A, Ctrl+C, paste) and redeploy, or edit knowledge.md in your repo.
